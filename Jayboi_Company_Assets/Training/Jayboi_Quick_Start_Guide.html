MC/DOT Authority Setup

Fee: $900 + $300 FMCSA
Timeline: 7-21 days

🔗 Direct Links

  • Filing Portal: https://li-public.fmcsa.dot.gov/LIVIEW/pkg_uis_landing.prc_login
  • SAFER Monitor: https://safer.fmcsa.dot.gov
  • IRS EIN Verify: https://www.irs.gov/businesses/small-businesses-self-employed/employer-id-numbers

✅ Quick Steps

Step 1: Gather Info (Day 1)

  • Legal business name & EIN
  • Business address
  • Cargo types
  • Officer names/DOB
  • Payment card

Step 2: File Application (Day 2-3)

  1. Go to: https://li-public.fmcsa.dot.gov/LIVIEW/pkg_uis_landing.prc_login
  2. Click “Register” → Create account with EIN
  3. Complete MCS-150 form (company info, cargo types)
  4. Complete OP-1 (operating authority)
  5. File BOC-3 (process agent)
  6. Pay $300 → Submit
  7. Save USDOT# and MC#

Step 3: Insurance & Activation (Day 4-21)

  1. Customer gets insurance ($750K minimum)
  2. Insurance broker files BMC-91X with FMCSA
  3. Monitor at: https://safer.fmcsa.dot.gov (check daily)
  4. When status = “Authorized” → Download authority letter
  5. Send customer: MC#, DOT#, SAFER snapshot

Driver Qualification File (DQF)

Fee: $223/year or $40/month
Timeline: 3-5 days

🔗 Direct Links

  • Medical Examiner Registry: https://nationalregistry.fmcsa.dot.gov
  • Clearinghouse: https://clearinghouse.fmcsa.dot.gov

✅ Quick Steps

Step 1: Get Documents

  • Driver’s license (front/back)
  • 3-year MVR (motor vehicle record)
  • Previous employer info (3 years)
  • DOT physical certificate
  • Drug test results

Step 2: Build File

  1. Employment application (§391.21)
  2. Order MVR from state DMV
  3. Send inquiries to previous employers
  4. Get road test OR previous employer certificate
  5. Verify medical examiner at: https://nationalregistry.fmcsa.dot.gov
  6. Schedule DOT drug test

Step 3: Annual Maintenance

  • Set calendar reminder for 12 months
  • Update MVR annually
  • Track medical cert expiration
  • Document all violations/accidents

Drug & Alcohol Consortium

Fee: $100/year
Timeline: Immediate

🔗 Direct Links

  • Clearinghouse: https://clearinghouse.fmcsa.dot.gov
  • Clearinghouse Login: https://clearinghouse.fmcsa.dot.gov/login

✅ Quick Steps

Step 1: Enroll Customer

  • Company info + MC/DOT#
  • Driver roster (names, DOB, contact)
  • Designate DER (employer rep)
  • Set up login credentials

Step 2: Random Testing

  1. Use random selection software (50% drug, 10% alcohol annually)
  2. Notify DER of selected drivers
  3. Driver goes to collection site within timeframe
  4. Results sent to MRO (Medical Review Officer)

Step 3: Report & Track

  • Register at: https://clearinghouse.fmcsa.dot.gov
  • Query drivers before hiring
  • Report positives within 2 business days
  • Keep records 5 years

UCR Registration

Fee: $76-$74,543 (by fleet size)
Timeline: Same day

🔗 Direct Links

  • Main Portal: https://www.ucr.gov
  • California: https://www.california-ucr.org
  • Texas: https://www.texas-ucr.org
  • Florida: https://www.flhsmv.gov/ucr
  • All States: https://www.ucr.gov/getting_started/state_contacts.php

✅ Quick Steps

Step 1: Determine Fee

  • 0-2 vehicles: $76
  • 3-5 vehicles: $230
  • 6-20 vehicles: $691
  • 21-100 vehicles: $3,459
  • [See full table in detailed guide]

Step 2: File (Same Day)

  1. Go to your state portal: https://www.ucr.gov
  2. Create account with USDOT#
  3. Enter business info
  4. Select registration year
  5. Input fleet size
  6. Pay with card → Submit

Step 3: Deliver Proof

  • Download receipt immediately
  • Email to customer (same day)
  • Set reminder for next December renewal

2290 Filing

Fee: $69.99-$100 + IRS tax
Timeline: Same day

🔗 Direct Links (Choose One)

  • ExpressHTUT: https://www.expresshvut.com (~$7-10/vehicle)
  • EasyForm2290: https://www.easyform2290.com ($69.99)
  • TaxExcise: https://www.taxexcise.com ($7.90+)
  • Form2290.com: https://www.form2290.com ($9.90+)

💰 Tax Table (2026)

Weight Annual Tax Monthly
55,000 lbs $100 ~$8
60,000-62,000 $550 ~$46
65,000 lbs $600 ~$50
80,000 lbs $800 ~$67

✅ Quick Steps

Step 1: Collect Info

  • EIN (9 digits)
  • VIN (17 characters) - verify carefully!
  • Gross weight (from registration)
  • First use month
  • Payment card

Step 2: File (Same Day)

  1. Go to: https://www.expresshvut.com (recommended)
  2. Create account → Login
  3. Enter EIN and business name
  4. Add vehicle: VIN, weight category, first use month
  5. Review tax calculation
  6. Pay with card → Submit

Step 3: Deliver Schedule 1

  • Download Schedule 1 proof (within minutes)
  • Email to customer immediately
  • Explain: Keep in vehicle + needed for DMV registration
  • Set reminder for July renewal

Dispatching Services

Fee: 8-10% of revenue
Timeline: Daily operations

🔗 Direct Links

  • DAT Load Board: https://www.dat.com
  • Truckstop: https://www.truckstop.com
  • 123Loadboard: https://www.123loadboard.com
  • SAFER (check authority): https://safer.fmcsa.dot.gov

✅ Quick Daily Process

Morning (6-9 AM):

  1. Check driver availability
  2. Review Hours of Service (HOS)
  3. Note locations and load needs

Search & Book (9 AM-12 PM):

  1. Log into load boards (DAT, Truckstop)
  2. Search by: driver location, equipment type, rate
  3. Calculate: True RPM = Revenue ÷ (loaded miles + deadhead)
  4. Call broker → Negotiate rate
  5. Get rate confirmation (RC) via email
  6. Assign load to driver

In Transit:

  • Pickup confirmation (get BOL#)
  • En-route check-ins
  • Delivery confirmation (get POD)

Invoice (Same Day):

  1. Gather: RC, BOL, POD
  2. Create invoice matching RC exactly
  3. Submit to broker AP
  4. Track in spreadsheet

Collections:

  • QuickPay: 24-48 hours
  • Standard: 30 days
  • Follow up: Day 31, 45, 60
