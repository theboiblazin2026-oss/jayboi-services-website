JAYBOI SERVICES, LLC - TRAINING GUIDE
======================================

This folder contains your complete service training guide in multiple formats:

FILES INCLUDED:
---------------
1. service_training_guide.md - Original Markdown (editable in any text editor)
2. Jayboi_Services_LLC_Training_Guide.docx - Microsoft Word format (editable)
3. Jayboi_Services_LLC_Training_Guide.html - Web page (view in browser, print to PDF)
4. style.css - Styling for HTML version

HOW TO USE:
-----------
• EDITING: Open the .docx file in Microsoft Word to make changes
• PRINTING: Open the .html file in your web browser and print (or Save as PDF)
• QUICK VIEW: Open the .html file in Safari, Chrome, or any browser

TO PRINT AS PDF:
----------------
1. Open "Jayboi_Services_LLC_Training_Guide.html" in your browser
2. Press Command+P (or File > Print)
3. Select "Save as PDF" from the PDF dropdown
4. Save to your desired location
