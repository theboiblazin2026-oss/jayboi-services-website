FMCSA Clearinghouse: What Carriers Need to Know

Published: January 19, 2026

The FMCSA Clearinghouse is a database that tracks drug and alcohol violations and refusals to test. Employers must query the database before hiring drivers and annually for current employees.

Employer Requirements

  • ✅ Pre-employment query - Required before hiring any CDL driver
  • ✅ Annual query - Must query each driver at least once per year
  • ✅ Report violations - Within 3 business days of occurrence
  • ✅ Register as employer - Free registration at clearinghouse.fmcsa.dot.gov

Query Types

Limited Query ($1.50): Shows if the driver has any records in the database. Requires driver consent if results are found.

Full Query ($1.50): Shows complete violation details. Requires driver's electronic consent.

Penalties for Non-Compliance

Carriers who fail to conduct required queries face fines up to $16,000 per violation and can be placed out of service.
